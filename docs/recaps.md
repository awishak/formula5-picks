# Commissioner's Reports (Recaps)

Weekly HTML recap files (round2.html, round3.html, etc.) produced each race weekend.

## Workflow

1. Export JSON from the F5 app.
2. Upload the JSON with race result screenshots.
3. Extract all scoring data programmatically from the JSON. Do not eyeball it.
4. I give verbal storyline direction.
5. Write the recap.
6. Iterate with targeted edits, not full rewrites.

## Formatting rules

No emojis.
No em dashes.
Bold all competitor names in body text.
Top 10: 48px circular player avatars with 20px team logos.
Matchup headers: 28px team logos.
Featured storyline section headers: 48px avatars.
Two paragraphs per section.
Order matchups by narrative interest, not by score margin.
Do not repeat the same information across the recap, matchup, and Top 10 sections.
Express standings as championship points and division placement, not win-loss records.
Output as standalone HTML files.

## Visual style

Fonts: Geologica and DM Sans.
Dark navy and blue palette.
Card-based layout. Rounded corners.

## Voice

First person. Self-deprecating. Punny. Inside jokes tailored to individual players (see docs/F5_Team_Lore.md). Fuller and more energetic, explanatory rather than stripped-down minimalist prose.
